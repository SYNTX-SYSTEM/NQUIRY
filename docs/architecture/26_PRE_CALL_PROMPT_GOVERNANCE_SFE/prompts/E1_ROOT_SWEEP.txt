RECURSIVE QUESTIONS
1. For each relation R-01 … R-12 of 02_RELATIONS.md: does a producer for its INPUT exist today? Does a
   consumer for its OUTPUT exist? Name the exact file/section or code symbol, or state ABSENT.
2. Order the ABSENT or broken relations by dependency. Which is first — i.e. which one no other broken
   relation depends on and which every later one needs? That is the root FBR. Justify "first".
3. For the root FBR: is it broken because (a) nothing exists, (b) something exists but violates an
   invariant (01_INVARIANTS.md), or (c) its authoritative home is undecided (Case 3)? Only (c) is a Human
   Authority boundary.
4. Does anything that already exists sit in the Field's path and would become a bypass once the Field is
   built (a route, a script, a provider adapter, a dev path) — e.g. any path from user text to
   ai_gateway? Recurse: what reaches it?
5. Is the SFE's own FBR list (00_FIELD.md §12) correct, complete and in the right order? If not, what is?
6. Recurse once more from the root FBR you found: assuming it were repaired, what becomes the next FBR?
   Stop recursing when the next FBR is a Human Authority boundary or a future Field (SEND, provider).

OUTPUT CONTRACT
- ROOT RELATION: the relation id, its producer/consumer, and why it is the root.
- FBR CHAIN: ordered list FBR-1 … FBR-n, each with evidence (file:section or code symbol), break type
  (a/b/c), and the relation(s) that depend on it.
- EXISTING-BYPASS REPORT: every path that could reach a provider, a Command or a log with user text
  without passing the Field; or "none", with the evidence searched.
- SFE CORRECTIONS: any correction to 00_FIELD.md §12, stated as a finding (you do not edit).
- HUMAN AUTHORITY: which FBRs are Case 3, mapped to HA-PCPG-* or to an existing HA-*.

STOP CONDITION
Stop when the FBR chain is derived up to the first Human Authority boundary or future Field, with evidence
for every link. Do not continue into design.

HUMAN AUTHORITY CONDITION
If the root FBR itself is a Case 3 (its authoritative home is undecided and no fail-closed default of
00_FIELD.md §13 applies), stop and state exactly that question — options, what each permits/forbids, the
fail-closed default — and nothing else.
