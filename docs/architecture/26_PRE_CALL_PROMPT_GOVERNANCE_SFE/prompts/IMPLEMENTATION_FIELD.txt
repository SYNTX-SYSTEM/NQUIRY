LOOP (repeat until a stop condition)
1. RUN ENRICO 7 (E1 → E7) against the CURRENT repository, not against memory. E1 gives the FBR chain;
   E7 gives the materialization order and the must-not-exist list.
2. TAKE THE CURRENT FIRST BROKEN RELATION. Exactly one.
3. DERIVE THE SMALLEST COHERENT DELTA that closes it:
   - the smallest change after which the relation's contract (02_RELATIONS.md), its boundary
     (03_BOUNDARIES.md) and its invariants (01_INVARIANTS.md) hold, and its proof can be executed;
   - REUSE existing producers (see REUSE below). If you find yourself writing a rule that an existing
     function already decides, stop: consume that function's result instead.
   - DO NOT CREATE PARALLEL CONCEPTS: no new authority class, role, permission boolean, state, status,
     lifecycle, policy, data class, operation contract, cache of authority, or persistence of observations.
4. WRITE THE FALSIFIERS FIRST and prove them RED against the unrepaired tree (for a new relation: against
   the predecessor checkpoint). Falsifiers come from 05 §1 (BLUE column) and the fixtures relevant to the
   relation.
5. MATERIALIZE the delta.
6. PROVE:
   - PRODUCER proof: the relation produces exactly its OUTPUT from its INPUT, and nothing else.
   - CONSUMER proof: each downstream relation consumes it correctly, and the existing producers it reads
     are unchanged (equivalence with the canonical capability results — P-14).
   - ADVERSARIAL proof: every 05 §2 case touching this relation fails for the stated reason.
   - MUTATION proof: each guard is necessary (removing or weakening it makes a falsifier pass wrongly).
   - PRESERVATION and REGRESSION: the full existing suite stays green; no existing producer changed
     behaviour; no route, Command, migration, provider path or frontend change appears unless the relation
     requires it.
7. RUN E6 (inverse sweep) over the new outputs. Any FABRICATED / DUPLICATED / STALE-CAPABLE / BYPASSED /
   PROMOTED finding is fixed at its entering relation before continuing.
8. RECONSTRUCT THE FIELD: record the relation as closed, its evidence, and the NEXT first broken relation.
9. CHECKPOINT per the line's discipline. Continue with the next FBR. One broken relation at a time.
