RECURSIVE QUESTIONS
1. For every Field-reconstruction item named in 00_FIELD.md §3 and the brief (FIELD, FIELD VERSION, SCOPE,
   WORKSPACE, SESSION, ACTOR, ROLE, MEMBERSHIP, PARTICIPATION, AUTHORITY, AUTHORITY SCOPE, CURRENT STATE,
   ACTIVE TRANSITIONS, SOURCE, SOURCE VERSION, SOURCE AUTHORITY, SOURCE MUTABILITY, EVIDENCE STATUS,
   PROOF STATUS, DATA CLASSIFICATION, DATA HANDLING RULES, PROVIDER POLICY, AIOP CONTRACT, CURRENT
   EXTERNAL EFFECT STATE, CURRENT DEPENDENCIES, INDETERMINATE RELATIONS): name its existing producer and
   version carrier, or state that none exists (then it is UNRESOLVED, not invented).
2. Which of these can only be known as an ABSENCE (e.g. "no binding")? How is an absence stated with its
   evidence, and why can no version key prove it current?
3. Derive the minimum Pulse: for each candidate element (active transitions, pending human decisions,
   pending authority requirements, in-flight operations, stale sources, recent authority change, current
   external dependencies, unresolved eligibility, indeterminate consequences, governance blockers) —
   which existing record or producer result is it a VIEW of? Drop any element with no canonical source.
   Prove no element duplicates a canonical concept.
4. Is there one consistent snapshot? Which reads must share it so that Pulse and reconstruction cannot
   disagree? What happens if a producer is unavailable (UNRESOLVED; never defaulted)?
5. Derive the freshness basis from dependencies: which inputs can change which stratum-3/4 value? Remove
   any dimension that cannot; add any that can. Prove (or refute) "derive on read; never a gate input".
6. Recurse: can any reconstruction item be influenced by the raw intent (scope widening, target naming
   an out-of-scope object, claimed version)? If yes, find the relation that lets it and repair it.

OUTPUT CONTRACT
- RECONSTRUCTION MAP: item → producer (file/symbol) → version carrier → absence handling → UNRESOLVED case.
- PULSE MODEL: element → canonical source → effect on evaluation; dropped elements with reason.
- SNAPSHOT RULE and FAILURE RULES.
- FRESHNESS BASIS: the derived dimensions with justification; the change classes that make an
  observation stale.
- SFE FINDINGS: corrections to §3/§9/R-03/R-04/R-14 (you do not edit).

STOP CONDITION
Stop when every item has a producer or an explicit UNRESOLVED rule, every Pulse element has a canonical
source, and the freshness basis is derived.

HUMAN AUTHORITY CONDITION
If an item required by the Field has no producer and its producer's home is undecided (e.g. data class of
free text: GAP-11-006), record the dependency on the matching HA-PCPG-* and apply its fail-closed default.
