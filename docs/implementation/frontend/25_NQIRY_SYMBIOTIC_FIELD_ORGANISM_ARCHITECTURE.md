
* presence
* relation tension
* semantic activation
* field breathing
* focus transfer
* contextual emergence
* traversal continuity

The system must feel alive without becoming busy.

Motion must be:


Not:

```txt

```



Projection authority correction:

Node size, relation current, orbit, and visual tone must derive from canonical semantics or explicit deterministic projection logic.

Background atmosphere is insufficiently organismic.

* background reads as visual backdrop
* depth is decorative rather than field-generating

Projection authority correction:

Atmosphere may express projected field state.

Projection authority correction:
