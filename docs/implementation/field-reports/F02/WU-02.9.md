# WORK UNIT REPORT
FIELD: F02 — CHALLENGE · SESSION · PARTICIPATION
WORK_UNIT: WU-02.9 — HTTP transport: common failure envelope, idempotency transport, F02 routes, server capability projections

## Mission
Expose every F02 Command/Query over real HTTP as thin adapters. Keep every outcome kind distinct. Carry idempotency to the application boundary. Give the frontend server-side capability projections, so it never computes authority.

## Relation materialized
`HTTP request (verified cookie + Idempotency-Key) → application.http_f02 → governed Command / Workspace-scoped Query → (status, envelope)`, and `resolved authority + shared preconditions → capability projection → UI affordance`.

## Initial state
- F02 Commands existed only in Python.
- F01/Arch-17 routes mapped malformed input to `{"kind": "denied"}` (Comprehension proof E9).
- `decide` passed `idempotency_key=None` (E10, F07 scope, untouched here).
- No capability projections for Challenges or Sessions on the wire.

## Files changed
- NEW `packages/application/http_f02.py`: dispatch + common failure envelope (`ok`, `committed`, `denied` 401/403, `rejected` 400, `stale` 409, `blocked` 422, `failed_precommit` 409, `indeterminate` 503, `not_found` 404); `Idempotency-Key` (UUID) required, used as `command_id` and idempotency key; Session id derived from the command id (a retry cannot create a second Session); canonical post-commit reread (`position`) returned with every Session Command
- NEW `packages/application/inquiry_queries.py`: `workspace_overview`, `challenge_detail`, `session_position`, each with `capabilities`/`actions` = `{available, reasonCode, reason}`; reasons generated server-side
- NEW `packages/persistence/inquiry_directory.py`: canonical listings (members, Challenges, Sessions, active bindings at an exact scope, the committed audit event that established the current Session state, exact match via `one_or_none`, no "latest")
- MOD `packages/application/session_control_handler.py`: pure blockers shared with projections (`prepare_burst_blocker`, `open_question_generation_blocker`, `method_setup_blocker`); `IdempotentReplay` + `_replay_guard` (before the STALE check, so a replayed committed transition is not misreported)
- MOD `packages/application/session_creation_handler.py`: `state_after_ref="session:DRAFT"`, Session as created ref, `SESSION_CREATED`, `result_ref`
- NEW `apps/api/src/nquiry_api/http/inquiry.py` (routes below); MOD `main.py` (router; CORS allows `Idempotency-Key`)
- MOD `apps/api/src/nquiry_api/http/workspaces.py`, `queries.py`: malformed input → `rejected` (E9 repair)
- NEW `tests/e2e/test_http_f02.py` (4 tests, real TestClient + real cookies + real DB)
